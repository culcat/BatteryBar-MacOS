# BatteryBar — Меню-бар macOS с оставшимся временем аккумулятора

Легковесное нативное приложение для macOS на языке **Rust**, отображающее оставшееся время работы от аккумулятора прямо в строке меню (menu bar / status bar).

## ⚡ Особенности

- **Нативный Cocoa/AppKit**: Без Electron, Tauri или WebView — бинарный файл весит всего ~2 МБ и потребляет ~10 МБ оперативной памяти.
- **Только Menu Bar**: Не занимает место в Dock (`NSApplicationActivationPolicy::Accessory`).
- **Информативное меню**: При клике на иконку открывается выпадающее меню с процентом заряда, источником питания, временем до разряда/заряда и кнопкой выхода (`Quit` / `Cmd+Q`).
- **Сверхнизкое энергопотребление**: 99.98% времени приложение находится в состоянии сна, не нагружая процессор.

## 🔋 Влияние на батарею

> **Короткий ответ: НЕТ, приложение практически не расходует батарею.**

### Подробное техническое объяснение:
1. **Интервал опроса (30 секунд)**:
   - Статус аккумулятора и прогноз оставшегося времени не меняются каждую секунду.
   - Опрос раз в 30 секунд означает всего **120 вызовов в час**.
2. **Время работы процесса**:
   - Вызов терминальной команды `pmset -g batt` занимает около **2–5 миллисекунд** процессорного времени.
   - За целый час суммарное процессорное время работы составляет:
     $$120 \times 0.003\text{ с} \approx 0.36\text{ секунды CPU на 1 час работы}$$
3. **Состояние покоя (Idle)**:
   - В перерывах между опросами фоновый поток полностью спит (`std::thread::sleep`), а главный поток ожидает нативных событий macOS RunLoop.
   - В мониторинге системы (*Activity Monitor*) показатель **Energy Impact** составляет `0.0` – `0.1`.
4. **Что могло бы сажать батарею (и чего здесь нет)**:
   - ❌ Бесконечные циклы без сна (busy loop) — отсутствуют.
   - ❌ Опрос с частотой 100 мс — отсутствует, чтобы не будить ядра Apple Silicon из глубоких C-states.
   - ❌ Браузерные движки (Chromium / WebView) — отсутствуют.

## 🛠 Как это работает

1. **Получение статуса**:
   Приложение исполняет команду:
   ```bash
   pmset -g batt
   ```
   Пример вывода:
   ```text
   Now drawing from 'Battery Power'
    -InternalBattery-0 (id=22741091)	76%; discharging; 3:15 remaining present: true
   ```
2. **Парсинг (модуль `battery.rs`)**:
   С помощью регулярных выражений извлекаются:
   - Процент заряда (например, `76%`)
   - Состояние (`discharging`, `charging`, `charged`, `ac attached`)
   - Оставшееся время (например, `3:15`)
   - Источник питания (`Battery Power` или `AC Power`)
3. **Нативный UI в стиле macOS Sonoma / Sequoia (`ui.rs`, `main.rs`)**:
   - **SF Symbols (`NSImage`)**: Иконка в статус-баре и все иконки пунктов меню используют системные монохромные темплейт-символы Apple (`battery.100percent`, `battery.75percent`, `battery.100percent.bolt`, `powerplug.fill`, `bolt.heart`, `arrow.2.squarepath`, `gearshape` и др.) с `setTemplate(true)`, которые автоматически адаптируются под светлую/темную тему и прозрачность обоев.
   - **Моноширинные цифры (`monospacedDigitSystemFontOfSize_weight`)**: Цифры времени и процентов в меню-баре не «прыгают» по ширине при смене значений.
   - **Карточка заголовка в стиле Control Center (`HeaderCardView`)**: Верхний элемент `NSMenu` содержит кастомный `NSView` с крупным заголовком **Battery**, процентом заряда справа, плавным капсульным прогресс-баром (`BatteryProgressBarView` на базе `NSBezierPath` с динамическими семантическими цветами `systemGreenColor` / `systemOrangeColor` / `systemRedColor`) и вторичными подписями (`secondaryLabelColor`).
   - **Аппаратная телеметрия (`ioreg -rc AppleSmartBattery -d 1`)**: Отображение здоровья аккумулятора (`Battery Health` в `%` и `mAh`), числа циклов перезарядки (`Cycle Count`) и текущего энергопотребления в ваттах (`Power Draw: W / V`).
   - **Выбор формата отображения (`Menu Bar Display`)**: Подменю с чекмарками для переключения формата на лету (`3h 15m · 76%`, `3:15 · 76%`, `3h 15m`, `76%`).
   - **Мультиязычная локализация (`i18n.rs`)**: Автоматическое определение системного языка macOS при запуске (`defaults read -g AppleLanguages` с фоллбэком на переменные окружения `LC_ALL` / `LC_MESSAGES` / `LANG`, по умолчанию — английский) и поддержка 5 языков (**English, Русский, Français, Español, 简体中文**), а также подменю `Language` (`globe`) для переключения языка интерфейса на лету без перезапуска.
   - **Быстрый переход в настройки (`Cmd+,`)**: Пункт `Battery Settings…` открывает системный раздел *System Settings → Battery*.

4. **Функционал обновления**:
   - **Ручное обновление статуса батареи**: Пункт меню `Refresh Now` (`Cmd+R`) для мгновенного считывания `pmset` и `ioreg` без ожидания интервала.
   - **Проверка обновлений приложения**: Пункт `Check for Updates…` (`Cmd+U`) и автоматическая фоновая проверка при запуске. Приложение обращается к GitHub API репозитория, сравнивает semver-версии и при наличии новой версии отображает `Update Available (vX.X.X) — Download…`, открывая страницу релиза в браузере. Модуль реализован в [`src/updater.rs`](src/updater.rs).

## 🚀 Сборка и запуск

### 0. Установка через Homebrew (Рекомендуется)
```bash
brew tap culcat/tap
brew install --cask battery-bar
```
Или одной командой:
```bash
brew install --cask culcat/tap/battery-bar
```

### 1. Запуск тестов
```bash
cargo test
```

### 2. Сборка оптимизированного релиза
```bash
cargo build --release
```

Исполняемый файл появится по адресу:
```bash
./target/release/battery-bar
```

### 3. Сборка пакета и установщика .DMG локально
```bash
./scripts/build_dmg.sh
```
Скрипт собирает бандл `BatteryBar.app` с нативным `Info.plist` (флаг `LSUIElement = true` для сокрытия из Dock) и упаковывает в `BatteryBar-0.1.0.dmg`.

### 4. Запуск
```bash
./target/release/battery-bar &
```
Приложение появится в верхнем правом углу строки меню macOS.

Чтобы завершить работу приложения:
- Нажмите на иконку в меню-баре и выберите **Quit** (или нажмите `Cmd+Q` при открытом меню).
- Либо выполните в терминале:
  ```bash
  killall battery-bar
  ```

## 🤖 Непрерывная интеграция (GitHub Actions)

В проекте настроен пайплайн [`.github/workflows/build-dmg.yml`](.github/workflows/build-dmg.yml):
1. **Кросс-компиляция**:
   - `aarch64-apple-darwin` (Apple Silicon M1/M2/M3/M4)
   - `x86_64-apple-darwin` (Intel Mac)
2. **Создание Universal 2 Binary**:
   - С помощью утилиты `lipo` бинарники объединяются в универсальный файл, работающий на всех поколениях Mac.
3. **Упаковка DMG**:
   - Создает `BatteryBar-Universal.dmg` с ярлыком `/Applications` для удобной установки Drag & Drop.
4. **Релизы**:
   - При пуше тега `v*` пайплайн автоматически формирует GitHub Release с прикрепленным `.dmg`.
   - При любом пуше в `main` или ручном запуске артефакт доступен во вкладке *Actions* для скачивания.

## ⚙️ Настройка интервала обновления

В файле `src/main.rs`:
```rust
const UPDATE_INTERVAL_SECS: u64 = 30; // интервал в секундах
```
- Рекомендуемое значение: `30` – `60` секунд.
