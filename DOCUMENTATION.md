# BatteryBar — Меню-бар macOS с оставшимся временем аккумулятора

Легковесное нативное приложение для macOS на языке **Rust**, отображающее оставшееся время работы от аккумулятора прямо в строке меню (menu bar / status bar).

## ⚡ Особенности

- **Нативный Cocoa/AppKit**: Без Electron, Tauri или WebView — бинарный файл весит всего ~2 МБ и потребляет ~10 МБ оперативной памяти.
- **Только Menu Bar**: Не занимает место в Dock (`NSApplicationActivationPolicy::Accessory`).
- **Информативное меню**: При клике на иконку открывается выпадающее меню с процентом заряда, источником питания, временем до разряда/заряда и кнопкой выхода (`Quit` / `Cmd+Q`).
- **Сверхнизкое энергопотребление**: 99.98% времени приложение находится в состоянии сна, не нагружая процессор.

## 🔋 Влияние на батарею

> **Короткий ответ: НЕТ, приложение практически не расходует батарею.**

### Подробное техническое объяснение:
1. **Интервал опроса (30 секунд)**:
   - Статус аккумулятора и прогноз оставшегося времени не меняются каждую секунду.
   - Опрос раз в 30 секунд означает всего **120 вызовов в час**.
2. **Время работы процесса**:
   - Вызов терминальной команды `pmset -g batt` занимает около **2–5 миллисекунд** процессорного времени.
   - За целый час суммарное процессорное время работы составляет:
     $$120 \times 0.003\text{ с} \approx 0.36\text{ секунды CPU на 1 час работы}$$
3. **Состояние покоя (Idle)**:
   - В перерывах между опросами фоновый поток полностью спит (`std::thread::sleep`), а главный поток ожидает нативных событий macOS RunLoop.
   - В мониторинге системы (*Activity Monitor*) показатель **Energy Impact** составляет `0.0` – `0.1`.
4. **Что могло бы сажать батарею (и чего здесь нет)**:
   - ❌ Бесконечные циклы без сна (busy loop) — отсутствуют.
   - ❌ Опрос с частотой 100 мс — отсутствует, чтобы не будить ядра Apple Silicon из глубоких C-states.
   - ❌ Браузерные движки (Chromium / WebView) — отсутствуют.

## 🛠 Как это работает

1. **Получение статуса**:
   Приложение исполняет команду:
   ```bash
   pmset -g batt
   ```
   Пример вывода:
   ```text
   Now drawing from 'Battery Power'
    -InternalBattery-0 (id=22741091)	76%; discharging; 3:15 remaining present: true
   ```
2. **Парсинг (модуль `battery.rs`)**:
   С помощью регулярных выражений извлекаются:
   - Процент заряда (например, `76%`)
   - Состояние (`discharging`, `charging`, `charged`, `ac attached`)
   - Оставшееся время (например, `3:15`)
   - Источник питания (`Battery Power` или `AC Power`)
3. **Отрисовка в macOS Menu Bar (`main.rs`)**:
   - Создается элемент `NSStatusItem` системного меню `NSStatusBar::systemStatusBar()`.
   - В безопасном контексте `objc2` через `run_on_main` заголовок кнопки обновляется на `🔋 3:15 (76%)` или `⚡ 1:20 (45%)`.
   - В выпадающее меню передаются подробные сведения.

## 🚀 Сборка и запуск

### 1. Запуск тестов
```bash
cargo test
```

### 2. Сборка оптимизированного релиза
```bash
cargo build --release
```

Исполняемый файл появится по адресу:
```bash
./target/release/battery-bar
```

### 3. Запуск
```bash
./target/release/battery-bar &
```
Приложение появится в верхнем правом углу строки меню macOS.

Чтобы завершить работу приложения:
- Нажмите на иконку в меню-баре и выберите **Quit** (или нажмите `Cmd+Q` при открытом меню).
- Либо выполните в терминале:
  ```bash
  killall battery-bar
  ```

## ⚙️ Настройка интервала обновления

В файле `src/main.rs`:
```rust
const UPDATE_INTERVAL_SECS: u64 = 30; // интервал в секундах
```
- Рекомендуемое значение: `30` – `60` секунд.
